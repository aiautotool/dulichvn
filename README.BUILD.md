# Vinago+ — Build & Rebuild Guide

Branch: `v2.1-chatgpt-ai`

This guide is for rebuilding the Expo/React Native app from a clean checkout.

## 1. Requirements

- Node.js 20+
- npm
- Git
- Android Studio + Android SDK for Android builds
- Xcode + CocoaPods for iOS builds on macOS

The project uses Expo SDK 56 and React Native 0.85.3. See `package.json` for the exact dependency versions.

## 2. Clone the AI branch

```bash
git clone -b v2.1-chatgpt-ai https://github.com/aiautotool/dulichvn.git
cd dulichvn
```

If the repository already exists:

```bash
git fetch origin
git checkout v2.1-chatgpt-ai
git pull --ff-only origin v2.1-chatgpt-ai
```

## 3. One-command setup

```bash
chmod +x scripts/*.sh
./scripts/setup.sh
```

`setup.sh` checks Node/npm, installs dependencies, creates `.env` from `.env.example` when needed, builds translation packs when available, and runs TypeScript validation.

## 4. Start development

```bash
./scripts/build.sh start
```

Or:

```bash
npm run start
```

## 5. Clean rebuild

Use this when dependencies, Expo cache, or native build state is broken:

```bash
./scripts/rebuild.sh
```

The command removes `node_modules` and `.expo`, reinstalls dependencies and runs type checking.

## 6. Run Android

### Emulator/device

```bash
./scripts/rebuild.sh android
```

Or:

```bash
npm run android
```

Make sure an Android emulator is running or a USB-debugging device is connected.

## 7. Run iOS

macOS only:

```bash
./scripts/rebuild.sh ios
```

If CocoaPods needs to be refreshed:

```bash
cd ios
pod install
cd ..
./scripts/rebuild.sh ios
```

## 8. Build web

```bash
./scripts/rebuild.sh web
```

The production web bundle is generated by Expo export.

## 9. AI configuration

Copy the example environment file if it has not already been created:

```bash
cp .env.example .env
```

Configure the server-side/remote AI endpoint according to the variables documented in `.env.example`.

**Never commit API keys or `.env` files containing secrets.**

The AI layer supports an OpenAI-compatible `/chat/completions` endpoint. The current implementation includes conversation history, intent detection, travel context, caching, timeout handling and a deterministic local fallback.

## 10. Type check only

```bash
npm run typecheck
```

## 11. Useful commands

```bash
# Install
npm install

# Start Expo
npm run start

# Android
npm run android

# iOS
npm run ios

# Web
npm run export:web

# TypeScript validation
npm run typecheck
```

## 12. Troubleshooting

### Metro/Expo cache problems

```bash
rm -rf node_modules .expo
npm install
npx expo start -c
```

### npm lock mismatch

Prefer the committed lockfile when present:

```bash
npm ci
```

### iOS native dependency problems

```bash
rm -rf ios/Pods ios/Podfile.lock
cd ios && pod install && cd ..
```

### Android Gradle problems

Clean the native project/build cache from Android Studio or run the appropriate Gradle clean command from `android/` if that native directory is present.

## 13. Recommended release flow

```bash
git checkout v2.1-chatgpt-ai
git pull --ff-only origin v2.1-chatgpt-ai
./scripts/setup.sh
./scripts/rebuild.sh
./scripts/rebuild.sh web
```

After validation, create the platform-specific release build using the project's configured Expo/EAS or native release pipeline.
